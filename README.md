# -PDE-SPDE-Agent-
对给定方程，在计算预算内选择时间步长和空间分辨率，达到指定误差要求；输出可复现的程序、误差表、收敛图及结论. Agent需要经历：  理解方程 → 选择数值方法 → 调用求解器 → 检查结果 → 诊断错误 → 调整参数 → 重新计算 → 提交报告.

## 任务分阶段设计（先确定性，再随机）

第一阶段优先使用 Allen–Cahn 等确定性方程，采用解析解或制造解算例，训练并评测以下能力：

- 根据方程与边界条件选择离散方法；
- 调整步长/网格使误差达到阈值；
- 定位边界条件、索引或符号错误；
- 判断结果是否进入渐近收敛区间；
- 在相同精度下比较计算成本。

第二阶段再进入随机问题（SPDE）。

## 强收敛验证器要求（SPDE）

强误差采用

\[
\widehat e(\tau,N)=\left[\frac{1}{M}\sum_{m=1}^{M}\left\|U_{\tau,N}^{(m)}(T)-U_{\rm ref}^{(m)}(T)\right\|^2\right]^{1/2}.
\]

验证器必须检查以下常见遗漏：

- **同噪声路径耦合**：强误差比较必须使用同一条噪声路径，不能比较两组独立噪声；
- **参考解误差控制**：参考解本身有离散误差，不能无条件当作真值；
- **时空误差解耦**：验证时间阶时需先压低空间误差，验证空间阶时需先压低时间误差；
- **样本量充分性**：蒙特卡洛样本不足时斜率可能只是统计波动；
- **复现与稳健性并重**：固定种子用于复现，更换种子用于稳健性检验，二者都要做。

### SCGL 实验解释原则

理论保证 \(1/2\) 阶并不意味着实验拟合斜率必须等于 \(1/2\)。观测到更高阶可能来自更强条件，也可能来自误差抵消或尚未进入渐近区间。因此，不能把“拟合斜率接近 0.5”机械地作为唯一正确性奖励。

## Reward 与过程反馈设计

### 1) 先保证正确，再奖励效率

可采用

\[
R = G(1-\lambda C)-(1-G)p,
\]

其中：

- \(G\in\{0,1\}\)：独立验证器判定任务是否正确完成；
- \(C\in[0,1]\)：归一化计算成本；
- \(0<\lambda<1\)：效率权重；
- \(p>0\)：未完成任务惩罚。

含义：先通过科学正确性门槛，再比较效率；不能通过减少样本、跳过检验或提前终止来“刷高效率”。

### 2) 过程反馈（诊断优先，不等同于奖励）

建议反馈映射：

- 结果出现 NaN/发散：检查步长、非线性处理、数值实现；
- 细化网格后误差不降：检查参考解、误差定义、其他主导误差项；
- 边界条件不满足：定位边界赋值、基函数或索引问题；
- 统计波动过大：增加独立样本并报告不确定性；
- 结果准确但成本高：在保持精度下优化分辨率或算法。

注意：过程反馈不应被简单等价为逐步加分（避免无意义工具调用或错误目标优化）。物理约束也必须按具体模型设定，例如随机 SCGL 不能无条件要求每条轨道能量单调下降。
